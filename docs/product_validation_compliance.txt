# Product Validation Compliance Rules

This document contains the compliance rules and validation requirements for product data validation.

---

## 1. Image Validation Requirements

All product images must meet the following minimum specifications:

| Requirement | Value |
|-------------|-------|
| Minimum Resolution | 1920×1080 (Full HD) |

### Image Validation Rules

- Product title and description should match with the contents of the image. Otherwise **failed**.
- Images smaller than 1920×1080 pixels are considered **invalid**
- Images meeting or exceeding 1920×1080 pixels are considered **valid**
- Images should not be blurred. if blurred it can be considered **Invalid**.
- Dominant object in the Image has to be the product mentioned. if not compliant ir can be considered **Invalid**
- Products without an image URL are marked as validation **failed**
- Images that fail to download or process are marked as validation **failed**
- Product title and description should match with the contents of the image. Otherwise **failed**.

## 3. Attribute Validation Rules

### 3.1 Validation Logic

1. **Check Product Type Existence**: If product type is not found, validation fails
2. **Determine Required Attributes**: Combine common attributes with product-type-specific attributes
3. **Check for Missing Attributes**: Attributes that are not present in the product data
4. **Check for Empty Attributes**: Attributes that exist but have `null` or empty string `""` values

### 3.2 Validation Status

| Status | Condition |
|--------|-----------|
| **Success** | All required attributes are present and have non-empty values |
| **Failed** | One or more required attributes are missing or empty |

### 3.3 Validation Response Fields

- `status`: "success" or "failed"
- `valid`: boolean (true/false)
- `message`: Human-readable validation message
- `missing_attributes`: List of attributes not present in product data
- `empty_attributes`: List of attributes with null or empty values
- `required_attributes`: Complete list of required attributes for the product type
- `provided_attributes`: List of attributes actually provided in product data

## 4. Compliance Notes

### 4.1 Choking Hazard Compliance

Products require a `choking_hazard` attribute for safety compliance. This is required across all defined product types.

### 4.2 California Prop 65 Compliance

Product type `3_14_63` requires the `prop_65` attribute for California Proposition 65 compliance related to warnings about chemicals known to cause cancer or reproductive harm.

### 4.3 PFAS Compliance

Product type `3_14_63` requires the `containsPFAS` attribute to indicate whether the product contains per- and polyfluoroalkyl substances (PFAS).

### 4.4 Perishable Products

All product types require the `perishable_indicator` attribute to indicate whether the product is perishable.

### 4.5 Large/Heavy Items (LTL)

Product type `3_14_63` requires the `is_ltl_item` attribute to indicate if the product requires less-than-truckload (LTL) shipping.
